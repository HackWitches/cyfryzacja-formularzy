# Cyfryzacja formularzy COI

Rozwiązanie zadania COI "Cyfryzacja formularzy" (HackNation 2026): serwis REST, który z papierowego formularza (PDF, DOC, DOCX, ODS, XLSX, JPG, JPEG, PNG) robi JSON z konfiguracją e-formularza do importu w Generatorze Formularzy COI.

- Serwis, Docker, konfiguracja i opis REST API: [service/README.md](service/README.md).
- Podgląd wyniku na tle papieru (narzędzie pomocnicze): `dev/visualize_output.py`.
